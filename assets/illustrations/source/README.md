# Master SVG illustrations

Place approved, self-contained SVG source files in this directory.

- Keep the original downloaded SVG unchanged unless a documented adaptation is required.
- Use lowercase kebab-case filenames (for example, `audit-team-review.svg`).
- Record the provider, exact asset/source URL, author when available, license, access date, modifications, intended pages, and corresponding WebP path in [the asset register](../../../docs/illustration-library/asset-register.md).
- Do not add an asset until its license and permitted commercial use have been checked.
- Do not reference files in this directory from public pages. Generate WebP files into `public/images/illustrations/` instead.

The SVG is the editable master; WebP is the production format served to visitors.
