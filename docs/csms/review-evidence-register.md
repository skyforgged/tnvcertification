## 5. Evidence index and control

For every record above, retain a resolvable controlled reference with:
- Unique record ID, title, version, creator, creation date and current status.
- Engagement and report version association.
- Source/origin, approval state and integrity/version information where relevant.
- Access classification, authorized roles and storage location.
- Links to predecessor/superseding records; never overwrite issued records.
- Retention/disposal rule from the approved document-control schedule and any legal hold.

Do not place sensitive client evidence in an uncontrolled register. Reference a secure controlled repository and verify access permissions.

## 6. Minimum evidence package for RA-07 closure

1. Management-approved technical review procedure, reviewer competence criteria, escalation authority and report-release delegation.
2. Named reviewer appointment(s) with verified competence evidence, permitted scope, current authorization and documented independence/conflict clearance.
3. At least one completed, authorized engagement technical review using the approved checklist, including review scope, inputs, criterion-by-criterion results and reviewer sign-off.
4. Complete review comment/correction log showing issue severity, author response, evidence, reviewer verification and closure of release-blocking issues.
5. Escalation record for any actual technical disagreement; if none arose, a documented rationale that no escalation was triggered for the reviewed engagement (this does not waive the escalation process).
6. Report approval and release record by a separately authorized approver, tied to the exact reviewed report version and distribution record.
7. Evidence that changes after review were controlled and re-reviewed where material.
8. Independent closure verification confirming the package is complete, authentic, current, traceable and effective.

A procedure, blank checklist, hypothetical exercise, meeting note, unsigned report, or reviewer name without verified competence/appointment is not sufficient to close RA-07. Technical review does not itself constitute certification, principal qualification or regulatory approval.
