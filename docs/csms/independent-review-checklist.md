## G. Report release gate (completed by authorized approver)

- [ ] Technical review outcome permits release.
- [ ] All major and release-blocking comments are closed with evidence.

- [ ] Released report version is identical to reviewed version or material changes have been re-reviewed.
- [ ] Factual review status and limitations are transparent.
- [ ] Scope, disclaimers, confidentiality and distribution are correct.
- [ ] Engagement, competence and impartiality gates remain valid.
- [ ] Approver holds documented delegation; technical reviewer sign-off is not treated as release authority.
- [ ] Report does not represent a principal, scheme-owner, certification or regulatory decision.
