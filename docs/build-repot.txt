8. Beranda dan halaman menu belum berbasis markdown
----------------------------------------------------
Pertanyaan: apakah halaman menu termasuk halaman depan dan apakah beranda
sudah memakai markdown, seperti contoh di
https://github.com/arisciwek/pusattraining/tree/main/src/content/pages

Temuan pada repositori ini:

- src/content/pages/ hanya berisi satu entri:
  0010-halaman-about-us.md.
- Beranda / adalah src/pages/index.astro, bukan entri markdown. Judul hero,
  deskripsi, tautan menu, dan judul bagian ditulis di file Astro dan komponen.
- Halaman menu /services/, /csms/, /trainings/, /schedules/, dan /articles/
  semuanya file .astro. Copy hero (eyebrow, title, description) dan CTA
  ditulis langsung di komponen, bukan di collection pages.
- Yang sudah markdown adalah halaman detail: artikel, layanan, dan training.
  Ini berbeda dengan halaman menu/indeks yang masih hardcoded.

Perbandingan dengan repo contoh:

- src/content/pages/ di repo contoh berisi home.md, jadwal.md, kontak.md,
  pelatihan.md, dan tentang-kami.md.
- home.md memakai pubDate dan updatedDate berformat ISO dengan offset
  +07:00, draft: false, serta blok seperti home-hero, home-introduction,
  home-category-overview, home-benefits, home-upcoming-schedule, dan
  home-contact.
- Dengan begitu, beranda dan halaman menu dikelola sebagai konten markdown,
  bukan copy di file .astro.

Kesimpulan: belum. Beranda dan halaman menu di repositori ini belum
mengikuti pola markdown pada repo contoh. Jika ingin konsisten, kopi teks
beranda dan tiap halaman menu perlu dipindahkan ke entri pages baru, lalu
halaman .astro menjadi renderer dari blok tersebut. Ini belum dikerjakan
